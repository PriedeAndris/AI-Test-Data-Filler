## Detailed description
AI Test Data Filler fills the form on your current tab with realistic, fictional test data in one click.

Built for testers and developers who are tired of typing "test test test":
- Random names, surnames, emails, addresses, dates and texts, different on every click.
- Data that stays consistent: a selected country drives the address, postal code and phone number; ages match dates of birth.
- Respects field types, length limits, number ranges, patterns and drop-down options.
- Picks drop-downs and radio buttons at random, and waits for dependent lists (such as regions) to load.
- Large-data test: fields that state a length limit (maxlength, a counter like 0/500, "max 500 characters") get long, readable text of exactly that length, ending in END so you can see if the form cuts it off.
- Never submits a form. Skips password, file and payment card fields.

Bring your own AI: you enter your own Claude (Anthropic) or ChatGPT (OpenAI) API key. The extension only talks to the provider you select, using your key. You pay that provider directly, typically a fraction of a cent per fill.

Privacy: your key stays in your browser. Only a description of the form's fields (labels, names, types, placeholders, options) and the choices already selected on the page are sent, and only to the provider you chose. Nothing you typed, no page text, no passwords. No analytics, no tracking.

Works on http and https pages. Custom widgets that are not standard inputs (some date pickers and searchable dropdowns) are not filled.

## Single purpose
Fill web forms with fictional test data generated by the user's own AI account.

## Permission justifications
- **activeTab:** read and fill the form on the tab the user clicked on, only after the click.
- **scripting:** inject the form-filling script into that tab.
- **storage:** keep the user's API key, model and preferences in the browser (local, not synced).
- **Host permissions api.anthropic.com and api.openai.com:** send the request to the AI provider the user selected, with the user's own API key.
- **Remote code:** none. All code is in the package.

## Privacy practices (dashboard form)
- Data collected: **Authentication information** (the user's API key, stored locally and sent only to their chosen AI provider) and **Website content** (descriptions of form fields on the current page, sent to the chosen AI provider to generate data).
- Not sold, not used for unrelated purposes, not used for creditworthiness or lending.
- Certify: data is used only for the single purpose above.
