AI Test Data Filler – Setup

The extension needs your own API key to write test data. You can save a key for Claude, ChatGPT or both, and choose which one is used. Only the selected provider is ever contacted.

Only providers that have a key saved can be selected.

What gets sent

When you click “Fill this page”, the extension sends the AI provider you selected a description of the fillable fields on the current page: labels, names, types, placeholders, allowed options, and the option currently selected in drop-downs and radio buttons (for example a chosen country). It does not send text you typed, passwords, cookies, the page title or address, or page text. It never submits a form. Keys are stored only in this browser (not synced) and are sent only to the provider they belong to. Use a key with a low spend limit.
