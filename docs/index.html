AI Test Data Filler

Fill any web form with realistic, fictional test data in one click, written by your own Claude or ChatGPT account.

Get the extension

What it does

  • Works on the current tab of any website.
  • Random names, surnames, emails, addresses and text, different on every click.
  • Respects field types, length limits, number ranges, patterns and drop-down options.
  • Never submits a form, and skips password and payment card fields.

Bring your own AI

On first run you choose Claude (Anthropic) or ChatGPT (OpenAI) and paste your own API key. You can save both keys, but the extension only ever contacts the one you select. Usage is billed to your account by that provider.

Install

Chrome Web Store: link coming once the listing is approved.

Until then: download the project, open chrome://extensions, enable Developer mode, choose Load unpacked, and select the extension folder.

Privacy

Your key stays in your browser. Only a description of the form fields on the page is sent, and only to the provider you chose. See the full privacy policy.
